# AI-Generated Decision Trees

This directory stores diagnostic decision trees generated by AI when users search for symptom combinations not covered by existing trees.

## Directory Structure

- **pending/**: Trees awaiting medical review and approval
- **approved/**: Trees that have been reviewed and approved for use
- **rejected/**: Trees that were rejected during review (kept for reference)

## Workflow

1. User searches for symptoms with no matching trees
2. AI generates a new decision tree automatically
3. Tree is saved to `pending/` with status "pending_review"
4. Medical professional reviews tree in admin interface
5. Approved trees move to `approved/` and become searchable
6. Rejected trees move to `rejected/` with reason documented

## Tree Metadata

Each tree includes metadata tracking:
- Generation timestamp
- AI provider used (OpenAI/Claude)
- Source symptoms
- Review status
- Approval/rejection timestamp and notes
- Version number

## Safety & Quality

All AI-generated trees include:
- Disclaimer about AI generation
- "Pending Review" status until approved
- Evidence-based medical content
- ICD-10 and SNOMED codes
- Differential diagnoses
- Clinical pearls and red flags
