# AI Content Enrichment - Quick Start Guide

## What Is It?

When you search for a diagnosis that has incomplete information (missing treatment, clinical pearls, referrals, or homeopathic remedies), RealDiag can now **automatically generate** this missing content using AI in real-time.

## Visual Example

**Before AI Enrichment:**
```
Search: "Polymyalgia Rheumatica"
Result:
  ✅ Name, ICD-10, SNOMED codes
  ❌ Treatment: (empty)
  ❌ Clinical Pearls: (empty)
  ❌ Referrals: (empty)
```

**After AI Enrichment:**
```
Search: "Polymyalgia Rheumatica"

🤖 AI-Enhanced Content
Some clinical information was generated by AI to supplement available data.
Enhanced sections: treatment, clinical_pearls, referrals

Result:
  ✅ Name, ICD-10, SNOMED codes
  ✅ Treatment:
     - Prednisone 15-20 mg daily initial dose
     - Taper over 12-18 months based on symptoms and ESR
     - Consider MTX as steroid-sparing agent
  ✅ Clinical Pearls:
     - Dramatic response to prednisone within 24-48h is diagnostic
     - Bilateral shoulder pain in patient >50 = PMR until proven otherwise
  ✅ Referrals:
     - Rheumatology: for diagnostic uncertainty or steroid resistance
```

## 5-Minute Setup

### Option 1: Interactive Setup (Easiest)

```bash
./setup_ai_enrichment.sh
```

Follow the prompts to configure Claude or OpenAI.

### Option 2: Manual Setup

1. **Get an API Key:**
   - **Claude (Recommended):** https://console.anthropic.com/
   - **OpenAI:** https://platform.openai.com/api-keys

2. **Add to `.env` file:**

   For Claude:
   ```bash
   ANTHROPIC_API_KEY=your_key_here
   AI_PROVIDER=claude
   ```

   For OpenAI:
   ```bash
   OPENAI_API_KEY=your_key_here
   AI_PROVIDER=openai
   ```

3. **Install packages:**
   ```bash
   pip install anthropic openai
   ```

4. **Restart backend:**
   ```bash
   # Your backend will auto-detect the API keys
   python -m uvicorn backend.main:app --reload
   ```

## How to Use

1. **Search any diagnosis** in the Diagnostic Search feature
2. **Look for the 🤖 icon** - indicates AI-enriched content
3. **Expand details** to see all generated clinical information
4. **Note the disclaimer** - always verify with current guidelines

## When Does It Trigger?

AI enrichment **only** activates when:
- ✅ A diagnosis is found in the database
- ✅ That diagnosis is missing one or more sections:
  - Treatment
  - Clinical pearls
  - Referrals
  - Homeopathic remedies
  - Workup
  - Presentations

**No enrichment** if:
- ❌ Diagnosis already has complete information
- ❌ No API keys configured
- ❌ API call fails (gracefully returns incomplete data)

## Safety Features

### Built-in Safeguards

1. **Clear Labeling**: All AI content shows 🤖 icon with disclaimer
2. **Section Tracking**: Lists exactly which sections were AI-generated
3. **Conservative Prompts**: Low temperature (0.3) for evidence-based responses
4. **Graceful Fallback**: Returns incomplete data if AI fails (no errors)
5. **Medical Disclaimer**: Instructs users to verify with guidelines and providers

### Medical Accuracy

- Prompts designed to follow current evidence-based guidelines
- Includes specific medications, dosages, and durations
- Professional medical terminology
- Conservative temperature setting
- Not a replacement for expert-curated content

## Troubleshooting

### "AI enrichment not working"

1. Check `.env` file has valid API key
2. Verify packages installed: `pip list | grep -E "anthropic|openai"`
3. Check backend logs for initialization messages
4. Try searching a diagnosis known to be incomplete

### "Content quality concerns"

1. Try switching providers (Claude vs OpenAI)
2. Check prompt in `backend/services/ai_content_enricher.py`
3. Temperature is already at conservative 0.3
4. Report specific issues for prompt refinement

### "Too slow"

1. Claude is faster than OpenAI (~2 sec vs 3-5 sec)
2. Content is cached after first generation
3. Consider pre-enriching all diagnoses during off-hours
4. Check API latency from your region

## Disabling AI Enrichment

**To disable:**
1. Remove API keys from `.env`
2. Or comment out the keys
3. Restart backend

The diagnostic search will work normally without AI enrichment, just with incomplete data for some diagnoses.
